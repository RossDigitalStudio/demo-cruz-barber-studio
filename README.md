# Demo Cruz Barber Studio

Landing conceptual para **Cruz Barber Studio**, desarrollada por Ross Digital Studio.

## Enfoque
- estética premium urbana
- negro, dorado y blanco
- responsive mobile / tablet / desktop
- animaciones al hacer scroll
- servicios, trabajos, promos, experiencia del local, horarios y ubicación
- CTA a Instagram como canal de reserva visible
- barra fija inferior en mobile

## Datos públicos utilizados
- Av. de Mayo 1202, Villa Adelina
- Lunes a viernes de 11:00 a 20:00
- Sábados de 10:00 a 20:00
- Domingo cerrado
- Instagram: @cruz.barberr

## Nota
Las imágenes son ilustrativas y de stock. La sección de promociones se presenta como un espacio genérico para campañas y no afirma que una promoción específica siga vigente. La demo incluye `noindex,nofollow` y no representa una web oficial del negocio.
